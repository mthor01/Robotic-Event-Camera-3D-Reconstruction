# Robot Recording and Event-Based 3-D Reconstruction

This branch contains the code used during my master's thesis, covering the
whole pipeline from robot-based data recording and calibration to
preprocessing, training, evaluation, and 3-D reconstruction.

The code is very hardware dependent and cannot be run directly: it was written
for one specific robot and camera setup, and it requires the Prophesee
Metavision SDK 4.6.2, which Prophesee no longer offers for public download.

To work with the method and the published dataset, use the
[`light` branch](https://github.com/mthor01/Robotic-Event-Camera-3D-Reconstruction/tree/light).
